# Airtable Schema — Oscar Legal Practitioners

## Base Name: `Oscar_Legal_Practitioners`

---

## Table 1: `Matters`

| Field Name | Type | Notes |
|---|---|---|
| `matter_id` | Single Line Text | Primary key. Format: `LP/YYYY/NNN`. Auto-generated by WF-02. |
| `matter_name` | Single Line Text | Auto-generated: `{matter_type} — {date}`. Lawyer-editable. |
| `parties` | Long Text | Real names of parties extracted from intake text via technical heuristics. (Preserves PII for lawyer records while bypassing LLM processing). |
| `status` | Single Select | `Open`, `Active`, `Pending Approval`, `Closed`, `Archived` |
| `channel` | Single Select | `whatsapp`, `telegram`, `email`, `web` |
| `intent` | Single Select | `litigation`, `drafting`, `research`, `client_communication`, `onboarding`, `advisory`, `general` |
| `matter_type` | Single Line Text | e.g. `Contract Dispute`, `Criminal Defence` |
| `urgency` | Single Select | `high`, `medium`, `low` |
| `gdrive_folder_id` | Single Line Text | ID of the Google Drive folder created for this matter. |
| `opened_date` | Date | ISO timestamp from intake |
| `last_activity` | Date | Updated on each interaction |
| `lawyer_id` | Single Line Text | From env var `DEFAULT_LAWYER_ID`. Future: lookup to Lawyers table |
| `drive_folder_url` | URL | Google Drive folder link for this matter |

---

## Table 2: `Clients`

> **Privacy Rule:** No real names, email addresses, or physical addresses stored in cleartext. Use token IDs only. PII is stored in a separate secure vault (future: Bitwarden / 1Password).

| Field Name | Type | Notes |
|---|---|---|
| `client_id` | Single Line Text | Secure token (e.g. `CLT-2026-0042`). Primary key. |
| `business_category` | Single Select | `Fintech`, `Real Estate`, `FMCG`, `NGO`, `Individual`, `SME`, `Government`, `Other` |
| `interests` | Multiple Select | Legal topics of interest e.g. `Arbitration`, `Property`, `Employment`, `Tax`, `Corporate` |
| `comm_preference` | Single Select | `email`, `whatsapp`, `telegram` |
| `active` | Checkbox | Is client currently active? (Used in CRM agent filter) |
| `matter_ids` | Long Text | Comma-separated list of associated matter IDs |
| `onboarded_date` | Date | Date of first interaction with the firm |
| `newsletter_opt_in` | Checkbox | Consent to receive newsletters |

---

## Table 3: `Drafts`

| Field Name | Type | Notes |
|---|---|---|
| `draft_id` | Single Line Text | Auto-generated: `DRAFT-{timestamp}` |
| `matter_id` | Single Line Text | Links to Matters table |
| `document_title` | Single Line Text | Title of draft document |
| `document_type` | Single Select | `motion`, `affidavit`, `agreement`, `letter`, `brief`, `engagement_letter`, `newsletter`, `article`, `other` |
| `version` | Single Line Text | e.g. `v1.0-2026-02-19` |
| `status` | Single Select | `Pending Approval`, `Approved`, `Rejected`, `Revised`, `Filed` |
| `drive_url` | URL | Link to Google Drive copy |
| `created_at` | Date | Creation timestamp |
| `approved_at` | Date | Approval timestamp |
| `instructions_to_lawyer` | Long Text | Actions needed before filing/sending |

---

## Table 4: `Agent Logs`

| Field Name | Type | Notes |
|---|---|---|
| `log_id` | Auto Number | Primary key |
| `matter_id` | Single Line Text | Associated matter |
| `agent_name` | Single Select | `orchestrator`, `research`, `drafting`, `crm`, `intake`, `system` |
| `action` | Single Line Text | e.g. `research_brief_generated`, `dispatch_plan`, `draft_created` |
| `input_hash` | Single Line Text | SHA-256 of input (for deduplication) |
| `output_hash` | Single Line Text | SHA-256 of output |
| `timestamp` | Date | ISO timestamp |
| `status` | Single Select | `success`, `failed`, `retried` |
| `error_message` | Long Text | Error details if status = failed |

---

## Table 5: `Approvals`

| Field Name | Type | Notes |
|---|---|---|
| `approval_id` | Auto Number | Primary key |
| `matter_id` | Single Line Text | Associated matter |
| `draft_id` | Single Line Text | Associated draft (if applicable) |
| `decision` | Single Select | `approved`, `rejected`, `revise`, `timeout_or_unknown` |
| `feedback` | Long Text | Revision notes or rejection reason |
| `approved_by` | Single Line Text | Sender ID (channel-specific handle) |
| `timestamp` | Date | Decision timestamp |

---

## Views to Create

| View Name | Table | Filter | Purpose |
|---|---|---|---|
| `Active Matters` | Matters | Status = Open OR Active | Daily matter dashboard |
| `Pending Approvals` | Drafts | Status = Pending Approval | Approval inbox |
| `High Urgency` | Matters | Urgency = high | Priority triage |
| `CRM Ready` | Clients | newsletter_opt_in = true AND active = true | Newsletter targeting |
| `Failed Logs` | Agent Logs | Status = failed | System monitoring |
